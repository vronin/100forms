# 100 TSD Forms

A personal forms library and progress tracker, built around a long-term goal: learn 100 Tang Soo Do (and adjacent) forms.

## Background

I train Tang Soo Do as my primary art and Hapkido as a secondary one. Along the way I discovered that I really enjoy learning new forms (hyung/poomsae/kata) — I memorize sequences quickly and can get them into decent shape, though not to competition-level polish. This project is about turning that interest into a long-term, trackable goal.

## Goal

Learn 100 forms over time: Tang Soo Do forms as practiced across different associations, plus adjacent forms from related arts (Taekwondo, Karate, Kung Fu, etc.) that are relevant to or influence Tang Soo Do practice.

## What this is

A website that acts as a library of forms, one page per form (or per form group, e.g. Pyung Ahn/Pinan/Heian as a family). Each page includes:

- **History** — when the form was created and by whom
- **Associations** — which organizations practice this form (and any naming/variation differences between them)
- **Stats** — number of moves and counts, number of kihaps
- **Videos** — links to reference videos found online (since plenty of practitioners perform these better than I currently do), plus my own recordings as I learn each form

## Progress tracking

Each form has a status:

- **Don't know** — not yet started
- **Learning** — currently working on it
- **Know but not recorded** — learned, no video of my own yet
- **Recorded** — learned and I have my own video

The site also shows an overall progress bar toward the 100-form goal, based on these statuses.
